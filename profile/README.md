This is in an effort to bring Small, Dumb but fast hardworking World models from the Indian Origin.

I've loved Iron Man since the first time I saw him and the following series so all of the models I produce will be named after the AI Models that Tony Stark creates:

- **Dum-E**: smallest model in the line-up, good for basic tool calling and fast working delegate.
- **E.D.I.T.H.**: a perfect summarization model with the focus on scope management/context compaction without losing emphasis.
- **J.A.R.V.I.S.**: Jev at a glance seems like a mess, jarvis shouldn't. Important for orchestrating delegation work and making sure provided outputs are correct more often than not.
- **A.I.D.A.**: Small but smart uncensored defense model estimated ~7B Params designed to work with [REA](https://github.com/morluto/rea) and browser search tools.
- **Vision**: Smart Reasoning model, a comfortable 7B params for one size fits all.
- **Ultron**: Largest uncensored defense model estimated ~24B Params and Q2, Q3, Q4 quantized to fit on 16GB macbooks
